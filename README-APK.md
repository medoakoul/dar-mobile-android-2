# بناء APK لتطبيق دار العقارية

افتح مجلد `android-project` في Android Studio، ثم انتظر اكتمال مزامنة Gradle، وبعدها اختر:

`Build > Build APK(s)`

سيظهر الملف داخل:

`app/build/outputs/apk/debug/app-debug.apk`

المشروع يستخدم ملفات التطبيق المحلية داخل `app/src/main/assets` ولا يغيّر منطق البحث أو العقارات أو المفضلة أو الطلبات.
